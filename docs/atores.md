# Atores Principais
Este documento identifica os principais atores dentro do contexto do sistema. Contudo, o protótipo não realizará a distinção dos tipos de usuários a fim de evitar complexidade excessiva.
Portanto, o protótipo terá apenas um tipo de usuário que fará todos os casos de uso.

## Solicitante
Registra solicitações de transporte de documentos ou volumes, informa origem, destino e prioridade, além de acompanhar o andamento da entrega.
- Registrar encomenda.
- Consultar encomendas.
- Acompanhar status.
- Consultar histórico de movimentações.

## Operador
Consulta as encomendas, organiza as entregas, atualiza o status da movimentação (aguardando coleta, em trânsito, entregue ou cancelada) e registra o motivo de cancelamento.
- Consultar encomendas.
- Editar encomenda.
- Alterar prioridade.
- Atualizar status.
- Cancelar encomenda.
- Consultar histórico de movimentações.
